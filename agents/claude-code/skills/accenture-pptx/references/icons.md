# Available Icons

Use the `icon` field to assign one icon per slide. Choose only when the slide content semantically matches — never add icons just to fill space. Set `"icon": null` when no match is strong.

| Key | Visual | Use when slide is about |
|-----|--------|------------------------|
| `"analyze"` | Magnifying glass | Analysis, research, search, findings |
| `"investigate"` | Browser + magnifier | Data investigation, discovery, exploration |
| `"compare"` | Scales / balance | Trade-offs, evaluation, comparison |
| `"goal"` | Flag + bullseye | Objectives, KPIs, results, targets |
| `"intelligence"` | Head with circuits | AI thinking, cognitive tasks, ML insights |
| `"ai_chip"` | CPU chip labeled "AI" | ML models, AI processing, architecture |
| `"agent"` | Hand with circuits | Agentic AI, human-AI interaction |
| `"metrics"` | Line chart with nodes | Trends, KPIs, performance, growth |
| `"dashboard"` | Pie chart on monitor | Reporting, analytics, dashboards |
| `"engineering"` | Wrench + screwdriver | Technical, maintenance, tooling, fix |

Icons apply only to `content_slide` with `layout: bullet_list` or `two_column`. Never on `card_grid`, `title_slide`, `section_divider`, or `closing_slide`.
